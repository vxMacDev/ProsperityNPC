# Security

## Reporting a problem

Please report security problems privately. Use **Report a vulnerability** on the repository's
Security tab. Do not open a public issue.

Include what you did, what happened and what you expected. A config and the server log lines help.

## What counts

Anything that could let someone:

- create money, or move money that should not move;
- get paid for a home they do not own;
- skip a payment check or a bill limit;
- read or change data they should not see;
- crash the server or hold up payments for everyone.

## Versions

Only the latest release gets fixes. This project is in beta, so test on a copy of your server before
you use it on a live one.
